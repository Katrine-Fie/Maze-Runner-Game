## The Prioritization Game

Single-page React app with a 2x2 value vs effort matrix. Drag feature cards from the backlog onto the matrix and they will stay where you drop them.
**Play live** https://katrine-fie.github.io/Maze-Runner-Game/

### Tech stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS

### Getting started

1. **Install Node.js** (if you do not have it yet)
   - Download the LTS version from `https://nodejs.org` and install it.

2. **Install dependencies**

   In PowerShell, run from this project folder:

   ```bash
   cd "c:\Users\kfhas\My first AI app"
   npm install
   ```

3. **Start the app**

   ```bash
   npm run dev
   ```

   Vite will print a local URL in the terminal (usually `http://localhost:5173`). Open it in your browser.

### How to use the app

- **Backlog sidebar**: On the left, you will see 5 sample feature cards (AI Chatbot, Dark Mode, Analytics Dashboard, Mobile App, Performance Optimization).
- **Drag & drop**: Drag a card from the backlog and drop it anywhere inside the matrix. It will stay exactly where you placed it.
- **Repositioning**: You can drag a card again from the matrix and drop it to a new spot.
- **Clear board**: Use the **“Clear board”** button to remove all placed cards and send them back to the backlog.
